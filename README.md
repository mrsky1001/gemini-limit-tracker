# Gemini Pro / Antigravity — Учёт лимитов

Расширение для Google Chrome, которое помогает следить за несколькими аккаунтами
с подпиской Gemini Pro / Antigravity: отмечать, на каком аккаунте закончился лимит,
автоматически считать время до его сброса, синхронизировать список между
компьютерами и смотреть статистику по каждому аккаунту.

## Установка (режим разработчика, без публикации в Chrome Web Store)

1. Распакуйте этот архив в любую папку на компьютере.
2. Откройте Chrome и перейдите на `chrome://extensions`.
3. Включите переключатель **«Режим разработчика»** (правый верхний угол).
4. Нажмите **«Загрузить распакованное расширение»**.
5. Выберите папку с файлами (там, где лежит `manifest.json`).
6. Иконка появится на панели расширений — закрепите её кликом на значок пазла.

Если расширение уже было установлено раньше — либо нажмите ⟳ «обновить» на
карточке расширения в `chrome://extensions`, либо удалите старую версию и
загрузите заново распакованную папку из этого архива. Существующие данные
(аккаунты, статусы, история) сохранятся автоматически.

## Как пользоваться

- При первом запуске список уже заполнен именами со скриншота — их можно
  переименовать, перекрасить или удалить через значок «⋮».
- **«+ Добавить аккаунт»** — добавляет новую карточку. Поле «Email» необязательное,
  но если его заполнить — появится рабочая кнопка быстрого открытия аккаунта (см. ниже).
- Переключатель (тумблер) справа от аккаунта — отметка «лимит закончился».
  - При включении, если для аккаунта ещё не задан автоинтервал, появится окно
    «Когда сбросится лимит?»:
    - **Автоматическая подстановка из буфера обмена**: если перед нажатием тумблера
      вы скопировали сообщение от Gemini или дату сброса, расширение само считает
      буфер обмена и подставит время (поддерживаются US-формат `9/4/2026, 3:01 PM`,
      русский/европейский `04.09.2026, 15:01`, месяцы словами и относительное время
      вида «через 4 часа» / «try again in 2 hours»).
    - Также можно нажать кнопку **«Из буфера»** для повторной вставки вручную
      или вставить сообщение в поле целиком — дата определится на лету.
    - Либо просто вручную выбрать дату/время в поле «Точная дата и время сброса».
  - Поставьте галочку **«Запомнить интервал»**, чтобы в следующий раз (если у
    аккаунта стабильный период, например ровно 24 часа) таймер запускался
    автоматически без повторного ввода — интервал считается как разница между
    указанным временем сброса и моментом отметки.
  - Отключить отметку вручную (если лимит вернули раньше) — просто выключите тумблер.
- Статус под именем аккаунта показывает обратный отсчёт: «через 1д 4ч 12м».
- Значок расширения показывает количество аккаунтов с закончившимся лимитом (бейдж).
- Когда время истекает, расширение само снимает отметку и присылает
  системное уведомление Chrome (можно отключить в настройках ⚙).
- **↗ «Открыть аккаунт»** — кнопка на карточке рядом с «⋮». Открывает в новой
  вкладке выбор Google-аккаунта (`accounts.google.com/AccountChooser`) с
  переходом на `gemini.google.com/app`. Если у аккаунта указан email — Chrome
  сразу предложит именно его; если нет — просто откроется список аккаунтов
  для ручного выбора.
- **📊 Статистика** (кнопка в настройках) открывает отдельную страницу в новой
  вкладке с данными по каждому аккаунту:
  - сколько раз лимит вообще заканчивался;
  - **эмпирический интервал** — среднее время между реальными отметками
    «лимит кончился» для этого аккаунта. Это фактический наблюдаемый цикл,
    который не нужно вводить руками — он считается сам по мере накопления истории;
  - средний заявленный период сброса (из введённых/распознанных дат);
  - последние отметки с датами и статусом сброса.
  - Кнопка «Очистить историю» стирает накопленную статистику (список аккаунтов
    и текущие лимиты не затрагиваются).
- **⬇ Экспорт JSON / ⬆ Импорт JSON** (в настройках) — сохраняют или загружают
  файл со списком аккаунтов, настройками и историей. При импорте можно выбрать:
  добавить импортированные аккаунты к текущим (объединение по id) или полностью
  заменить список. Полезно перед переустановкой Chrome или для переноса на
  другой компьютер вручную (в дополнение к автоматической синхронизации).
- В настройках (⚙ в правом верхнем углу попапа):
  - период по умолчанию, который подставляется в окно ввода периода;
  - включение/выключение уведомлений;
  - сортировка — показывать ограниченные аккаунты первыми (по времени сброса).

## Синхронизация между компьютерами

Список аккаунтов и настройки хранятся в `chrome.storage.sync` — Chrome сам
синхронизирует их между всеми компьютерами, где вы вошли в один и тот же
Google-аккаунт (обычно занимает несколько секунд). При первом запуске после
обновления расширение один раз переносит уже имевшиеся локальные данные в sync
автоматически — ничего делать не нужно.

У Chrome sync есть ограничение по размеру (~8 КБ на список аккаунтов, этого
хватает на несколько десятков аккаунтов). Если список окажется слишком большим,
расширение покажет предупреждение и сохранит данные только локально на этом
устройстве — используйте экспорт/импорт JSON как резервный способ переноса.

История отметок для статистики хранится только локально (`chrome.storage.local`)
на каждом устройстве отдельно, поскольку она может расти и не обязана быть
одинаковой на всех компьютерах.

## Технические детали

- Manifest V3, permissions: `storage`, `alarms`, `notifications`, `clipboardRead`.
- `shared/storage.js` — общий модуль для попапа, service worker'а и страницы
  статистики: аккаунты/настройки идут в `chrome.storage.sync` (с автоматическим
  fallback на `local` при превышении квоты), история — в `chrome.storage.local`.
- Фоновый service worker (`background.js`) проверяет таймеры каждые 5 минут
  через `chrome.alarms`, снимает отметки и шлёт уведомления, даже если попап
  закрыт; также слушает `chrome.storage.onChanged`, чтобы обновлять бейдж при
  изменениях, пришедших синхронизацией с другого устройства.
- `stats.html` / `stats.js` / `stats.css` — отдельная страница статистики,
  открывается в новой вкладке через `chrome.tabs.create`.
- Кнопка «Открыть аккаунт» ведёт на `accounts.google.com/AccountChooser` —
  это официальный экран выбора Google-аккаунта, никаких паролей расширение
  не хранит и не видит.
